# UI/UX Design Standards — Mandatory

- **No emojis:** Never use emojis in the UI, navigation, buttons, headings, notifications, empty states, or other application content. Use a consistent professional icon library such as Lucide instead.
- **Flat UI design:** Use a clean, modern, flat design with clear visual hierarchy, solid colors, subtle borders, minimal shadows, and consistent spacing. Avoid excessive gradients, glassmorphism, glowing effects, and unnecessary animations.
- **Human-designed appearance:** Avoid generic AI-generated layouts and repetitive dashboard cards. Make intentional design decisions based on the application's actual users, workflows, and business requirements.
- **Professional visual language:** Use a restrained color palette, consistent typography, readable font sizes, and carefully balanced whitespace. Establish design tokens for colors, spacing, borders, typography, and component states.
- **Consistent components:** Build reusable buttons, inputs, tables, dialogs, dropdowns, badges, navigation, and form components. Keep their styles and behavior consistent throughout the application.
- **Data-dense interfaces:** For administrative pages, prioritize useful information, well-designed tables, filters, search, pagination, clear status indicators, and practical actions over decorative dashboard cards.
- **Subtle interactions:** Use purposeful hover, focus, active, loading, and disabled states. Keep transitions short and avoid distracting animations.
- **Responsive and accessible:** Support mobile, tablet, and desktop layouts. Follow accessible contrast standards, keyboard navigation, semantic HTML, and visible focus indicators.
- **Meaningful content:** Use realistic sample data and clear, natural interface copy. Avoid generic placeholder text, unnecessary marketing language, excessive labels, and repetitive descriptions.
- **Functional UI:** Every visible interactive element must perform its intended action. Implement proper loading, empty, success, validation, and error states.
- **Design references:** Before building the UI, establish a cohesive design system and inspect existing project styles. If reference designs are provided, follow their visual direction without blindly copying unrelated elements.

### Design Acceptance Criteria
Before considering a page complete, verify that:
1. No emojis are used as interface icons or decorative elements.
2. The layout follows a consistent flat design system.
3. Typography, spacing, colors, borders, and component states are consistent.
4. The page looks professional and purpose-built, not like a generic AI-generated template.
5. All interactions, responsive layouts, accessibility basics, and UI states have been verified.
